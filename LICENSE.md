## 1. Yang Anda Boleh

- Menggunakan source code ini untuk **satu** website atau usaha Anda sendiri
- Mengubah, menyesuaikan, menambah, atau menghapus fitur
- Mengganti nama, warna, logo, foto, harga, dan seluruh isi konten
- Menjalankan website di hosting milik Anda sendiri, gratis maupun berbayar
- Memperbaiki sendiri, atau meminta bantuan orang lain
- Menjual produk dari website ini (pemesanan, membership, dan sejenisnya)
  kepada pelanggan Anda

## 2. Yang Tidak Boleh

- Menjual, menyewakan, atau mendistribusikan ulang source code ini, mentah
  maupun dimodifikasi, sebagai template, tema, atau paket source code
  untuk orang lain
- Membuat ulang produk sejenis dari kode ini lalu menjualnya ke orang lain
- Menghapus atau mengubah penulis hak cipta yang ada di dalam file
- Meng klaim kode ini sebagai karya Anda sendiri
- Menggunakan nama atau merek pembuat asli untuk produk Anda

> Ringkasnya: **pakai untuk usaha Anda sendiri = boleh.**
> **Menjual ulang source code-nya = tidak boleh.**

## 3. Komponen Pihak Ketiga

Project ini memakai pustaka pihak ketiga lewat CDN. Lisensi masing-masing
tetap berlaku pada file aslinya.

| Komponen                 | Dipakai lewat | Lisensi                 |
| ------------------------ | ------------- | ----------------------- |
| Tailwind CSS             | CDN           | MIT                     |
| Google Fonts             | CDN           | SIL Open Font License   |
| Foto demo (Unsplash)     | URL gambar    | Unsplash License        |

Semua ikon pada project ini adalah **SVG inline** yang dibuat khusus untuk
template ini, jadi tidak ada pustaka ikon pihak ketiga yang perlu dipasang.
Bila Anda memakai CDN di atas saat deploy, pastikan alamatnya tetap bisa
dijangkau pengguna (atau unduh ke folder `vendor/` bila ingin maksimal
offline).

## 4. Tanpa Jaminan

Source code ini disediakan **"sebagaimana adanya"**, tanpa jaminan apa pun,
termasuk jaminan bahwa kode bebas dari kesalahan, cocok untuk platform tertentu,
atau siap dipakai. Penulis tidak bertanggung jawab atas:

- Kerugian akibat salah isi nomor WhatsApp, harga, atau alamat
- Kehilangan data yang tersimpan di browser pengguna (localStorage atau IndexedDB)
- Gangguan layanan pihak ketiga (WhatsApp, Google Maps, CDN, hosting)
- Kerugian lain yang muncul dari penggunaan source code ini

## 5. Batas Tanggung Jawab

Sejauh diizinkan oleh hukum yang berlaku, tanggung jawab penulis dibatasi pada
jumlah yang Anda bayarkan untuk source code ini.

## 6. Perubahan atas Lisensi Ini

Anda boleh menambah ketentuan tambahan milik Anda sendiri (misalnya ketentuan
privasi atau dukungan purna jual) dan umumnya menyusun ulang dokumen ini,
**asalkan** ketentuan pada bagian 1 dan 2 — terutama larangan menjual ulang
source code — tidak dihapus atau diperlemah. Bagian 3, 4, dan 5 tetap berlaku
apa pun yang tertulis.
